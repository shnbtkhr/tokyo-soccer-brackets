# 強さの点数（Elo レーティング）の仕様

このプロジェクトのスカウティングサイトで「強さの点数」と呼んでいる数値の定義。
AI（Claude Code・Gemini・NotebookLM など）がこの数値を読む・説明する・変更するときの正本とする。

## 位置づけ（最初に読むこと）

- **設計者**: Claude Code（2026-09-11 に初版、2026-09-15 に改訂）
- **ユーザーの判断**: 「リーグ戦（地区リーグ）を強さの点数に入れる」（2026-09-15）。設定の値は Claude Code が過去の試合で比べて選んだ
- **状態**: 2022〜2026 年度の大会の試合で当たり具合を確かめた（notes/rating_backtest.md）。2025・26 年度の大会 1,314 試合で、見込みの高い側が勝った割合 80.2%
- それでも「過去の試合からの目安」。断定的な予想には使わない

## 何を表す数値か

東京都の高校サッカー部の強さを、全校共通の物差しで並べた点数。始まりは 1500。
試合の勝ち負けに応じて動く。点数の差から「勝つ見込み」を計算できる。

## 計算手順（rating.py）

1. **使う試合**: 大会（総体・選手権・新人戦・関東予選）と、リーグ戦（Tリーグ T1〜T5・プリンスリーグ関東・第1〜8地区のリーグ）
2. **チームの分け方**: 大会は学校のトップチーム。リーグ戦は「学校の A チーム＝学校」「控え（B・C…）＝学校とは別のチーム」「クラブ＝別のチーム」
3. **並べ方**: 日付順。大会で日付の書かれていない試合は、同じ大会・段階で一番早い日付（それも無ければ段階の目安日）に置く
4. **最初の点数**: 大会の学校は 1500。リーグ戦で初めて出てくる控えは、その学校の A の点数から B は 100・C は 200…引いた値。
   それ以外（クラブなど）は、リーグの階層で決める（プリンス +300・T1 +200・T2 +150・T3 +100・T4 +50・T5 ±0・地区1部 −50・2部 −100・3部 −150）
5. **試合前の見込み**: `E_A = 1 / (1 + 10^((R_B − R_A) / 400))`（差 0 点 → 50%、100 点 → 約 64%、200 点 → 約 76%）
6. **結果**: 勝ち S=1、負け S=0、PK 戦 S=0.5（引き分けとして扱う）
7. **点差の倍率** G（得点差 m）: m ≤ 1 → 1.0、m = 2 → 1.5、m ≥ 3 → (11 + m) / 8
8. **更新**: `Δ = K × W × G × (S_A − E_A)`、`R_A += Δ`、`R_B −= Δ`。W は大会 1.0・リーグ戦 0.5
9. **仮の期間**: 試合数が 10 未満のチームとの試合では、相手（試合数の多い側）の点数は動かさない。まだ点数が当てにならないチームの結果で学校の点数を崩さないため
10. **年度の区切り**: 点数を平均へ戻さない（CARRY = 1.0）

## パラメータ（rating.py の ADOPTED）

| 名前 | 値 | 根拠 |
|---|---|---|
| BASE | 1500 | Elo の慣例（全体が平行移動するだけ） |
| K | 88 | 32〜88 で比べて一番当たった。大会は1校あたり年に数試合しかないので、1試合で大きく動かすほうが今の強さに追いつく |
| CARRY | 1.0（戻さない） | 0.75・0.9・1.0 で比べて 1.0 が一番当たった。学校ごとの強さ（指導・部員の集まり方）が年度をまたいでも続くためとみられる |
| リーグ戦の重み W | 0.5 | 0.1・0.25・0.5 で比べて 0.5 が一番当たった |
| 控えの差 | 1段 100 点 | 置いた値（B チームが A より弱いことを表す） |
| 仮の期間 | 10 試合 | 置いた値 |
| 点差の倍率 | 上記 | サッカー向け Elo（World Football Elo）でよく使われる式 |
| PK 戦 | 0.5 | 80 分で決着していないため |
| 格上・格下の線 | ±50 点 | 見込みで約 57% / 43% にあたる差。検証なし |

K と CARRY は比べた範囲の端が一番良かった。K をさらに大きくすると少し良くなる可能性があるが、1試合で点数が大きく動きすぎるので K88 で止めた。

## 使うデータ

- **大会**: 東京都高体連サッカー専門部のトーナメント表 PDF 74 本から読み取った公式戦（2022〜2026 年度。out/matches.csv）
- **Tリーグ**: 2025・2026 年度（data/leagues/tleague_matches.csv。2024 年度以前はサイトに残っていない）
- **プリンスリーグ関東1部**: 2026 年度（data/leagues/prince_kanto1_2026_matches.csv）
- **地区リーグ**: 2024〜2026 年度（data/leagues/district_matches.csv）。日付の無い試合は使わない
- **除外**: スコアのない試合、未実施の試合、不戦勝・棄権
- **学校の同定**: `build_outputs.normalize()` ＋ `scout/school_aliases.json`。昭和第一（文京区）と昭和第一学園（立川市）は別の学校
  - 2026-09-11: 表記ゆれで同じ学校が別チームになっていた60組を統合（notes/name_merge_proposal.md・ユーザー承認済み）
  - 2026-09-15: 地区リーグの略称（都西・城西・電大高 など）と、控えの印の読み取り（芝A・東海大高輪台F など）を直した
- **順位**: 大会に出る学校のうち、5 試合以上ある学校の中での順位（控えやクラブは順位に入れない）

## 当たり具合（notes/rating_backtest.md）

| | 対数損失 2025-26 | 的中率 2025-26 | 対数損失 2024 |
|---|---|---|---|
| 旧方式（大会だけ・K32・CARRY 0.75） | 0.565 | 76.8% | 0.578 |
| 今の方式（ADOPTED） | 0.471 | 80.2% | 0.479 |

**リーグ戦をそのまま入れると悪くなった**（地区リーグには強い学校の控えやクラブが多く、みな 1500 から始まるため、学校の点数が崩れた）。
控えの最初の点数・仮の期間・リーグの重み 0.5 を入れて、はじめて大会だけより良くなった。

## この点数から出している数字

- **勝つ見込み**（武蔵丘が相手に勝つ）: 現在の点数を手順 5 の式に入れた値
- **この山を勝ち抜く見込み**: 山の組み合わせに沿って各試合の見込みを掛け合わせる。終わった試合は結果どおり（`analyze_team.block_probabilities`）
- **当たる確率**: 武蔵丘と相手の両方がその試合まで勝ち上がる見込み。候補2校を足すと「武蔵丘がその回戦まで進む見込み」になり、100% にはならない（`build_site.meet_breakdown`）
- **格上・格下・同格**: 試合の時点（更新する前）の点数の差で判定。差 > 50 が格上、< −50 が格下

## 既知の弱点

1. 2022 年度の序盤は全校が 1500 から始まるため不正確
2. 地区リーグは地区ごとに取れる年度・部が違う（第8地区は学校の試合記録だけ、第1地区は 2025 年度なし など）。取れた量の多い地区の学校ほど点数がよく動く
3. ホーム・アウェー、延長の有無、PK の勝敗を区別しない
4. 控えの差（100 点）・仮の期間（10 試合）・階層の最初の点数は置いた値で、個別には比べていない

```
uv run python build_outputs.py       # 大会（out/matches.csv）
uv run python collect_tleague.py     # Tリーグ
uv run python collect_districts.py   # 地区リーグ
uv run python analyze_team.py        # 点数と山の見込み（out/scout/*.json）
uv run python rating_backtest.py     # 設定を変えたら当たり具合を比べ直す（notes/rating_backtest.md）
uv run python build_site.py          # サイト（out/site/）。公開用は --links artifact
```
