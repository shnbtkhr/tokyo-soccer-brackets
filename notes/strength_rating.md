# 強さの点数（Elo レーティング）の仕様

このプロジェクトのスカウティングサイトで「強さの点数」と呼んでいる数値の定義。
AI（Claude Code・Gemini・NotebookLM など）がこの数値を読む・説明する・変更するときの正本とする。

## 位置づけ（最初に読むこと）

- **設計者**: Claude Code（2026-09-11 のセッション）。ユーザーが明示的に承認した設計ではない
- **状態**: 暫定。過去の試合で予想の当たり具合を検証していない（検証・調整はユーザーの判断待ち）
- **ユーザーの意思表示**: 「勝率分析をしたい」「武蔵丘との力の比較を見たい」まで。計算方法と下記のパラメータは Claude Code が選んだ
- この数値を根拠に断定的な予想を書かないこと。「過去の公式戦からの目安」として扱う

## 何を表す数値か

東京都の高校サッカー部の強さを、全校共通の物差しで並べた点数。平均は 1500。
試合の勝ち負けに応じて少しずつ動く。点数の差から「勝つ見込み」を計算できる。

## 計算手順

1. **初期値**: すべての学校を 1500 点から始める（データの最初の 2022 年度から）
2. **試合前の見込み**: 学校 A が学校 B に勝つ見込み
   `E_A = 1 / (1 + 10^((R_B − R_A) / 400))`
   差 0 点 → 50%、100 点 → 約 64%、200 点 → 約 76%
3. **結果**: 勝ち S=1、負け S=0、PK 戦 S=0.5（PK の勝敗にかかわらず引き分けとして扱う）
4. **点差の倍率** G（得点差 m）:
   - m ≤ 1 → 1.0
   - m = 2 → 1.5
   - m ≥ 3 → (11 + m) / 8（3 点差 1.75、5 点差 2.0、10 点差 2.625）
5. **更新**: `Δ = K × G × (S_A − E_A)`、`R_A += Δ`、`R_B −= Δ`（ゼロサム）
6. **年度の区切り**: 各年度の最後の試合のあと、全校の点数を平均へ戻す
   `R ← 1500 + (R − 1500) × CARRY`
7. 最後に処理した時点の点数を「現在の点数」とする

## パラメータ

| 名前 | 値 | 根拠 | 変えたときの影響 |
|---|---|---|---|
| BASE | 1500 | Elo の慣例 | 全体が平行移動するだけ |
| K | 32 | Elo の一般的な値（チェスの若年層など） | 大きいほど直近の結果に敏感になり、ぶれも大きい |
| CARRY | 0.75 | 部員が毎年入れ替わる（3 年で総入れ替え）ことを考えて置いた値。検証なし | 小さいほど前年の強さを引き継がない |
| 点差の倍率 | 上記 | サッカー向け Elo（World Football Elo）でよく使われる式 | 大差の勝ちを重く見るかどうか |
| PK 戦 | 0.5 | 90 分（80 分）で決着していないため | 1/0 にすると PK に強い学校が高く出る |
| 格上・格下の線 | ±50 点 | 見込みで約 57% / 43% にあたる差。検証なし | 広げるほど「同格」が増える |

値の定義場所: `analyze_team.py` の `BASE, K, CARRY`（格上・格下の線は `build_site.py` の `band_of`）。
サイトの説明（入口ページ「強さの点数のしくみ」）は、この定数から数値を読んで表示している。

## 使うデータと並べ方

- **対象**: 東京都高体連サッカー専門部のトーナメント表 PDF 73 本から読み取った公式戦 4,010 試合（2022〜2026 年度）
  総体（支部予選・一次・二次）、選手権（一次・二次）、新人戦（地区大会）、関東大会東京都予選
- **除外**: スコアのない試合、未実施の試合、不戦勝・棄権。T リーグ・地区リーグ（NS・DUO・リバーサイド等）の結果は**入っていない**
- **学校の同定**: `build_outputs.normalize()`（「都・」「都立」などを外す）＋ `scout/school_aliases.json`。昭和第一（文京区）と昭和第一学園（立川市）は別の学校として扱う
  - 2026-09-11: 表記ゆれで同じ学校が別チームになっていた60組（関東一/関東第一、東京成徳/東京成徳大学/東京成徳大高、多摩科技/多摩科学技術 など）を統合した（notes/name_merge_proposal.md・ユーザー承認済み）。点数を付けた学校は 346 → 306 校
- **時系列**: 年度 → 大会の段階（関東予選 → 総体 支部予選 → 一次 → 二次 → 選手権 一次 → 二次 → 新人戦）→ 回戦の順。同じ回戦の中の順序は区別しない（PDF に日付がない試合が多いため）

## この点数から出している数字

- **勝つ見込み**（武蔵丘が相手に勝つ）: 現在の点数を手順 2 の式に入れた値
- **この山を勝ち抜く見込み**: 山の組み合わせ（8 校のトーナメント）に沿って、各試合の見込みを掛け合わせて厳密に計算。終わった試合は結果どおり（`analyze_team.block_probabilities`）
- **当たる確率**: 武蔵丘と相手の両方がその試合まで勝ち上がる見込み（`build_scout_page.build_data`）
- **格上・格下・同格**: 試合の時点（その試合で更新する前）の点数の差で判定。差 > 50 が格上、< −50 が格下（`analyze_team.compute_elo` が各試合に試合前の点数を記録）
- **順位**: 5 試合以上ある学校の中での順位

## 既知の弱点

1. パラメータを検証していない（上表の「根拠」を参照）
2. 2022 年度の序盤は全校が 1500 から始まるため不正確。その時期の格上・格下の判定も甘い
3. 試合数の少ない学校、地区が違う学校どうしの比較は、たどれる試合のつながりが少なく不安定
4. 今季のリーグ戦を含まないので、今の調子を反映しない（例: 昭和第一は 2026 年の DUO リーグで首位だが、点数では下位）
5. ホーム・アウェー、延長の有無、PK の勝敗を区別しない
6. 年度内の同じ回戦の試合順は近似

## 検証のやり方（未実施・案）

- 2025〜2026 年度の各試合を、その試合の直前までの点数で予想し、的中率とブライアースコアを出す
- K・CARRY・PK の扱いを変えて比べる（過去に合わせすぎないよう、調整に使う年度と確かめる年度を分ける）
- リーグ戦を加える案（Antigravity の引き継ぎ文書 A-2「直近の調子の補正」）も同じ方法で比べる
