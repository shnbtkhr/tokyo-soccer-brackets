# 学校名の統合案（表記ゆれで同じ学校が別チームになっている）

作成: 2026-09-11（Claude Code）。**2026-09-11 ユーザー承認・反映済み**（A の50組を scout/school_aliases.json の exact_map に入れ、強さの点数を計算し直した。点数を付けた学校は 346 → 312 校）。

## 見つけたきっかけ

Tリーグの「東京成徳」が大会データの「東京成徳大高」とつながらなかった。調べると、大会データの中でも同じ学校が「東京成徳」「東京成徳大学」「東京成徳大高」の3チームに分かれていた（高体連の PDF が大会ごとに違う書き方をしているため）。
強さの点数は学校ごとに計算するので、分かれていると**試合数が割れて点数が不正確になる**（例: 関東一 4試合と関東第一 30試合が別々に計算されている）。

調べ方: out/matches.csv（4,010試合）の学校名を、「大学／大／大高／附属」などの違いを除いた形や共通の語根でまとめ、候補ごとに地区・大会を見て同じ学校かを判断した。
