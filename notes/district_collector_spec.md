# 地区リーグの結果を集める部品の仕様（districts/）

作成: 2026-09-11（Claude Code）。地区ごとの部品を並列のサブエージェントが作るための共通の決まり。
まとめ役は collect_districts.py（Claude Code が書く）。サイトの「地区リーグ」ページと、強さの点数（ステップ3）で使う。

## 部品の形

- ファイル: `districts/d1.py` 〜 `districts/d8.py`（地区ごとに1つ。共通の下請けが要るときは `districts/_<名前>.py`）
- 公開する関数は1つ:

```python
def collect(refresh: bool = False) -> tuple[list[dict], list[dict]]:
    """(順位表の行, 試合の行) を返す。refresh=False のときは保存済みのページだけで動く（ネットに出ない）。"""
```

- 取得したページは `raw/web/district/dN/` に保存し、`refresh=True` か未保存のときだけ取りに行く。同じサイトへは 1.5 秒以上あける。User-Agent は `Mozilla/5.0 (Windows NT 10.0; Win64; x64)`
- URL は data/leagues/sources.csv にある確認済みのもの、またはそのページの中のリンクからたどったものだけを使う（番号を変えて作らない）

## 順位表の行（dict のキー。T リーグの tleague_standings.csv と同じ並び）

| キー | 値 |
|---|---|
| 地区 | "第3地区" など |
| リーグ | "第3地区ユースリーグ"・"DUOリーグ"・"NSリーグ" など |
| 年度 | int（2026 など） |
| 部 | "1部"・"3部D"・"グループB" など（ページの書き方） |
| 順位 | int。分からなければ "" |
| チーム | ページの表記そのまま（"成立学園C" など） |
| 学校 | `normalize(base)` |
| 区分 | "A"・"B"・"C"…（印の無いものは "A"） |
| 勝点・試合・勝・分・敗・得点・失点・得失点 | int。分からなければ "" |
| 出典 | そのページの URL（試合から計算したときは末尾に "（試合から計算）"） |

チーム名の分け方: `from collect_tleague import squad_of` → `base, sq = squad_of(チーム)`、`from build_outputs import normalize` → `学校 = normalize(base)`。
クラブチーム（FC・SC・ユース など）もそのまま入れてよい（まとめ役がクラブかどうかを判定する）。

## 試合の行

| キー | 値 |
|---|---|
| 地区・リーグ・年度・部 | 順位表と同じ |
| 節 | 文字列。分からなければ "" |
| 日付 | "YYYY-MM-DD"。分からなければ "" |
| ホーム・アウェイ | ページの表記そのまま（ホームとアウェイの区別が無ければ左・右） |
| ホーム得点・アウェイ得点 | int。未実施なら "" |
| 実施 | "済" か "未" |
| ホーム学校・ホーム区分・アウェイ学校・アウェイ区分 | 順位表と同じ分け方 |
| 出典 | URL |

## 年度

2026年度は必須。2025・2024年度は、同じサイト・同じ読み方で取れるものだけ（追加の推測が要るものはやらない）。

## 確かめ方（部品ごとに必ず行う）

1. `uv run python -c "from districts import dN; s, m = dN.collect(); print(len(s), len(m))"` が動く（環境変数 PYTHONIOENCODING=utf-8）
2. 順位表の各行で 試合 = 勝 + 分 + 敗、勝点 = 3×勝 + 分（ページの数字と違う場合はページを正とし、メモに残す）
3. 1つの部を選び、ページを目で見た内容（1位のチーム・勝点・試合数）と一致することを確かめる
4. 試合の行から数えた勝敗が、順位表と大きく食い違わない

## やってはいけないこと

- 担当以外のファイルを作る・変える（districts/ の自分のファイルと raw/web/district/dN/ だけ）
- git の操作
- Playwright などのブラウザを使う（呼び出し元と共有しているため）
- 1件ずつ確認を求めて止まる（機械的な作業なので、最後まで走り切ってからまとめて報告する）
