# 名寄せの影響（2026-10-02）

名寄せ（校名の書き方がちがう同じ学校を1校にまとめる作業。判断の一覧は Vault の `school_merges.csv`、62件）を当てる前と後で、強さの点数・順位・サイトの出力がどう変わったかを測った。「前」は旧データそのまま（`SOCCER_SOURCE=legacy`）、「後」は名寄せ後の表から組み立て直したものである。

- **点数・順位・試合数の見方**：点数は `rating.py` の現在値、順位は大会に出た学校（538校 → 502校）の中での点数順、試合数は点数の計算に使った試合の数（大会＋リーグ戦）。
- 名寄せの影響は2経路ある。(1) **別の学校が1校になる**（試合が合算され、点数・順位が動く）。(2) **同じ試合が二重に数えられていたのが1回に戻る**（下の「二重記録」33試合）。
