## 依頼

東京都の高校サッカー（U-18）の「地区リーグ」について、2024・2025・2026年度の**試合結果と順位表が載っているページの URL** を、第1〜8地区のすべてについて探してください。

## 探し方のヒント

- goalnote（https://www.goalnote.net/ ）には多くの地区リーグがある。大会ページの URL は detail.php?tid=数字。大会名で検索し、tid を必ず控える
- ほかに Google サイト（sites.google.com/view/...）、独自ドメインのサイト、Jimdo・Wix などの無料サイト、各校サッカー部のページ（「○地区リーグ 2部 残留」などの記載からリーグ名が分かる）、X・Instagram の公式アカウント（リンク集が載っていることが多い）
- 検索語の例: 「第3地区 ユースリーグ」「3地区 U-18 リーグ 東京」「東京都 第8地区 ユースリーグ 結果」「8地区ユースリーグ 順位」「第6地区 リーグ 高校サッカー 東京」「goalnote 東京 地区 U-18」、各区・市の名前＋「高校 サッカー リーグ 順位」
- 学校のサッカー部ページに「○○リーグ 1部 3位」とあれば、それを手がかりにリーグ名を特定する

## 守ってほしいこと

- **推測で URL を作らない。** 実際に開いて、試合結果または順位表が載っていることを確かめたものだけを「確認済み」とする
- 開けなかった、ログインが必要だった、SNS の投稿でしか確認できなかった、などは状態欄に正直に書く
- 見つからなかった地区・年度も、「未発見」として必ず表に残す（何も書かないと、探したのか探していないのかが分からないため）
- 高校の名前が「A」「B」などでチームを分けている場合は、その書き方をそのまま書き写す

## 出力の形式

次の2つを出してください。

1. 地区ごとの見出しで、見つかったリーグの説明（リーグ名、部とブロックの構成、参加チーム数の目安、運営・更新の様子、根拠にしたページ）
2. 最後に、次の列の CSV（1行 = 1つのリーグの1つの年度の1つの部）。値にカンマを含めない

    地区,リーグ名,年度,部・ブロック,結果ページのURL,順位表ページのURL,形式,goalnote_tid,チームの区別,状態,根拠のURL,メモ

   - 形式: goalnote / Googleサイト（スプレッドシート埋め込み） / 独自サイト / PDF / SNSのみ / 不明
   - チームの区別: A・B・Cの表記あり / 表記なし / 不明
   - 状態: 確認済み / 一部確認 / SNSのみで確認 / 未発見
