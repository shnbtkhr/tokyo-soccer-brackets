大会概要

名称 NSリーグ２０２５
大会期間 2025年03月01日（土） ～ 2025年11月09日（日）
参加チーム数 45チーム
大会方式 リーグ戦
試合方式 延長なし・PKなし
試合時間 前後半制
45分ハーフ　(90分)
勝点 勝利 3 点　/　引分け 1 点　 /　敗戦 0 点
順位決定方法 優先順位
(1)勝点
(2)得失点差
(3)総得点
(4)当該チーム間の対戦成績
(5)抽選
警告の累積 警告の累積が 3 回で出場停止処分とする。
